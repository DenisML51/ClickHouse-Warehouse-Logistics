Высокопроизводительная система моделирования и оптимизации складской логистики. Позволяет минимизировать штрафы за задержки поставок в сложной сети распределения товаров с использованием колоночной СУБД **ClickHouse**.

---

## Описание задачи

Логистическая сеть состоит из **N складов** (графовая топология). В системе распределены **100 000 объектов** различных типов ($K < 100$). Заказчики формируют поток заявок, требующих наличия конкретных товаров на конкретных складах.

### Ключевые ограничения:
- **100 000 объектов** распределены по складам неравномерно.
- **Ограничение хода:** За одно действие можно перемещать товары только **одного типа $K$**.
- **Динамика перемещения:** Время доставки зависит от характеристик товара (`move_time`) и веса ребра графа.
- **Штрафная система:** Каждый шаг ожидания заявки увеличивает общий штраф на +1.

---

## Многоуровневая предиктивная эвристика

В проекте реализован **Multi-layer Heuristic Predictive Solver**. Это гибридный алгоритм, который сочетает в себе скорость жадных алгоритмов и эффективность систем с глубоким планированием.

### Почему этот подход — лучший?

1.  **Баланс скорости и точности:** В отличие от методов линейного программирования, которые «задыхаются» на 100 000 объектов, наш алгоритм работает за линейное время $O(N)$, обеспечивая мгновенный отклик даже в сложных сетях.
2.  **Предиктивность (Look-ahead):** Система не просто ждет появления заявок, она анализирует будущий спрос. Если товар понадобится через 50 ходов, он может начать движение уже сейчас.
3.  **Адаптивное управление ресурсами:** Алгоритм учитывает «излишки» на складах, предотвращая ситуации, когда выполнение одной заявки создает дефицит для другой в ближайшем будущем.
4.  **Механизм «Анти-голодания»:** Интеллектуальное чередование типов товаров гарантирует, что транспортный канал не будет монополизирован одним типом $K$, а все заказчики получат свои товары.

## 🛠 Установка и запуск

### 1. Подготовка окружения
Мы используем современный менеджер пакетов `uv` для быстрой и надежной работы.

```bash
# Установка зависимостей
uv sync
```

### 2. Запуск инфраструктуры
Для работы необходим ClickHouse, который разворачивается одной командой:

```bash
docker-compose up -d
```

### 3. Запуск оптимизатора
```bash
uv run main.py
```

## Тестовые сценарии

Система включает 6 калиброванных тестов для проверки различных топологий:

| # | Название | Топология | Описание |
|---|----------|-----------|----------|
| 1 | **Идеальный случай** | Звезда | Товары на местах, проверка базовой логики. |
| 2 | **Магистраль** | Цепочка | Проверка перемещения на длинные дистанции. |
| 3 | **Центральный хаб** | Звезда | Высокая нагрузка на один узел. |
| 4 | **Кольцо** | Кольцо | Альтернативные маршруты и распределение. |
| 5 | **Сетка (Grid)** | Сетка 5x4 | 50 типов товаров, проверка многозадачности. |
| 6 | **Случайный** | Random | Хаотичное распределение для стресс-теста. |

## Схема данных ClickHouse

- `object_types`: Справочник характеристик товаров.
- `warehouse_graph`: Описание логистических связей.
- `initial_inventory`: Срез состояния складов на старте.
- `order_list`: План заявок.
- `movements`: **Результат работы** — оптимальная последовательность действий.
